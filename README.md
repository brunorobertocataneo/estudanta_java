# Exercícios de notas em Java

Exercícios de entrada de dados e cálculo com notas. [Resolucao1.java](b/Resolucao1.java) usa um vetor e caixas de diálogo do Swing para receber cinco notas e calcular a média. [Exercicio1.java](b/Exercicio1.java) registra uma tentativa com `Scanner`.

## Executar o exemplo com Swing

Com o JDK instalado e em um ambiente com interface gráfica:

```bash
cd b
javac Resolucao1.java
java Resolucao1
```
